# EEG Features & Machine Learning

訊號處理提供特徵，統計建模描述關聯，機器學習用訓練資料建立預測；跨受試者泛化與資料洩漏需謹慎。

來源：[S06](../papers/S06.md)，§3–4。參照 paper note 的原文定位；獨立科學審查仍待完成。

## 一個建模範例

X 可表示受試者的特徵向量，例如頻譜峰與 exponent；y 是預先定義的任務標籤。訊號處理產生 X，機器學習使用訓練樣本學習從 X 到 y。

**直觀例子：** 若同一受試者的重疊片段同時出現在訓練與測試，結果可能過度樂觀；依受試者切分可評估跨人泛化。

**定位：** [S06](../papers/S06.md) §1.1.2、§3–4；此切分為教學評估建議。。
